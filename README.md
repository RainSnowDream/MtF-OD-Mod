# MtFOD Mod

> 珍爱生命，远离毒品。

一个**警示药物滥用与过量（OD，Overdose）危害**的 Minecraft Fabric 模组。

本模组按真实药理学模拟国内被滥用的处方药的作用与危害，让玩家直观感受药物滥用的后果，尤其是过量（OD）的致命性。内容仅供**公益/教育**用途，不构成用药指导，也不美化或鼓励任何药物使用。

## 机制

- **药效分期**：用不同持续时间的效果叠加，近似「初始兴奋 → 高峰幻觉/共济失调 → 后遗乏力」。
- **视觉幻觉**：致幻类药品（右美沙芬 / 愈美片 / 金刚烷胺）附带「黑暗脉冲」。
- **幻听**：致幻类药品激活时，随机播放原版恐怖洞穴环境音（`ambient.cave`）。
- **获取**：
  - 创造模式「食物与饮品」标签页；
  - 生存模式：**牧师（Cleric）** 会出售全部药品（药房交易）。
- **清除**：喝**牛奶**可清除所有状态效果。
- **成就**：「第一次 OD」——首次服用滥用药时触发。

## 构建

```bash
gradlew.bat build        # Windows
./gradlew build          # macOS / Linux
```

产物：`build/libs/mtfodmod-0.1.0-beta+fabric+26.3.jar`。放入 Fabric 实例的 `mods/` 目录即可（需同时安装 Fabric API）。
