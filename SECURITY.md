# 安全策略 / Security Policy

## 支持的版本

仅支持**最新发布版**。旧版本不再单独修复安全问题。

## 报告安全问题

如果你发现安全问题（例如可被利用的崩溃、存档损坏、或隐私/数据相关问题），请**不要**直接开公开 Issue。

请通过 GitHub 的私密安全公告报告：

1. 打开仓库 **Security** 标签页 → **Advisories** → **New draft security advisory**
2. 描述问题、复现步骤与影响

我们会尽快响应并处理。

---

If you find a security issue (e.g. an exploitable crash, world corruption, or a privacy/data problem), please **do not** open a public issue.

Report it privately via GitHub Security Advisories:
1. Open the repository **Security** tab → **Advisories** → **New draft security advisory**
2. Describe the issue, reproduction steps and impact.

We will respond as soon as possible.
